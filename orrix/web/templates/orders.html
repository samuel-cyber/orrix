Order ledger

Seller-asserted shipment records, matched to disputes by the seller's transaction id.

The ledger arrives in a later phase: an add form, CSV import with a per-row error preview, and a searchable table.

Ledger entries are seller-asserted, not carrier-verified. Orrix records when a row was stored so it can show whether a record predates the dispute; it never treats that as proof the carrier confirmed anything.
